# README

Googleスプレッドシートに作成した月次タスク一覧表をGoogleカレンダーをトリガーに更新していく。

## 動作

簡単にまとめると、「実行時点から1週間後の予定を見る」「過去1カ月の予定を確認」という2つの処理を定期実行する。


### ① 来週までに予定されているタスクをチェックしてSlackに投稿する


1. **カレンダーから1週間先までの終日イベントを取得**
    `getAllDayEventsWithinNextWeek()` が、今日から7日以内の日付に登録されている終日イベントを取得する。

2. **イベントに対してシートを作成**
    
    - `TEMPLATE` シートをコピーして新規シートを作成
    - シート名をイベントのタイトルに変更
    - `A2` セルにイベントタイトル、`A4` セルにイベント開始日時を書き込み

    このとき、既にシートが存在するイベントはスキップし、重複作成を防ぐ。

3. **通知対象があればSlackに投稿**


### ② 過去1カ月（当日含む）の予定を確認し、未了タスクをSlackに投稿する


1. **カレンダーから終日イベントを取得**
    `getAllDayEventsWithinMonth()` が、当日から過去31日分の範囲でカレンダーの終日イベントを取得する。このイベントの「タイトル」がスプレッドシートの「シート名」に対応している前提。

2. **イベント名と同名のシートを探す**
    取得した各イベントについて、タイトルと同名のシートが存在するか確認する。存在しない場合はスキップする。

3. **未了タスクを収集する**
    `collectPendingTasks()` が、対象シートの7行目以降（データ開始行）を読み込み、以下の列構成を前提に未了タスクを抽出する。

    | 列 | 内容 |
    |---|---|
    | A列 | タスク名 |
    | B列 | 完了フラグ（`false` = 未了） |
    | C列 | 担当者名 |
    | D列 | バッファ（未使用） |
    | E列 | 開始日 |
    | F列 | 開始条件 |
    | G列 | 猶予（未使用） |
    | H列 | 期限日 |

    完了フラグが `false` かつ担当者が入力されていて、そのうえで開始日を過ぎている行を対象に、「担当者 → 期限日 → タスク名一覧」という階層構造（`Map<string, Map<string, string[]>>`）に集約する。期限日は `yyyy/MM/dd` 形式の文字列に変換し、文字列比較で日付昇順ソートする。

    なお、このときに「開始条件」列が指定されていると、そこで指定したタスクが完了になっているかを先にチェックする。
    指定したタスクが完了して初めてタスクとしてカウントするので、「始めようがないのに督促される」という状況を回避できる。

4. **Slackに投稿**
    未了タスクが1件でもあるシートについてのみSlackへ投稿する。タスクが0件のシートは通知をスキップする。


## 準備

### Googleカレンダー

カレンダーを新規作成し、雑誌の校了日を ***終日イベントとして*** 登録しておく。

### Googleスプレッドシート

最低限必要なシートは `TEMPLATE` と `MEMBER` という名前のシート2枚。

`TEMPLATE` シートは下図レイアウト。

![img](./images/template-sample.png)


| セル番地 | 内容 |
| --- | --- |
| `A2` | タスク名 |
| `A4` | 基準日 |

6行目にヘッダ。左7列は以下で固定。

| セル番地 | 内容 |
| --- | --- |
| `A6` | 工程 |
| `B6` | 完了 |
| `C6` | 担当者 |
| `D6` | バッファ |
| `E6` | 開始日 |
| `F6` | 猶予 |
| `G6` | 期限日 |

7行目以降は下記書式にしておくこと。

| 列 | 書式 |
| --- | --- |
| `B` | チェックボックス |
| `E`・`G` | 日付 |

`MEMBERS` シートは下図レイアウト。

![img](./images/member-sample.png)

- 1行目がヘッダ
- A列に名前
- B列にSlackID

### Google Apps Script

スクリプトエディタを開いて、サイドバー下端の `プロジェクトの設定` からスクリプト プロパティとして以下の3つを設定する。

- `CALENDAR_ID` …… GoogleカレンダーのID
- `SHEET_ID` …… GoogleスプレッドシートのID
- `WEBHOOK_URL` …… Slackアプリとしてチャンネルに投稿するためのURL。
    - https://api.slack.com/apps/ からアプリのページに移動して `Incoming Webhooks` セクションからチャンネルごとに発行する

以下をそれぞれ毎日定期実行するようにトリガーを設定しておく。

- `task1.gs` の `checkNextTask`
- `task2.gs` の `checkCurrentTask`


## 開発者向け


### 環境構築

使用ツール：npm

> [!NOTE]
> TypeScriptで開発しているので初回は `npm install` すること。

### 開発手順

使用ツール：[clasp](https://github.com/google/clasp)

> [!NOTE]
>  まっさらな状態から開始するなら `clasp create-script` コマンドでプロジェクトを初期化し、生成された `.clasp.json` の `scriptId` 以外を[ここ](.clasp.json)に合わせて編集する。

[`./src`](./src/) 配下の `*.ts` ファイルを更新したら、

- `npm run push` でローカルの変更をGASエディタに反映し、
- `clasp open-script` でGASエディタを開く
